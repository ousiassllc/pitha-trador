## 質問

1. 詳細ページの見出し「注文提案 #5」とブロック名「トレードシグナル #2」「注文 #3」「ポジション #2」は、Issue 番号ではなくデータの ID なので「#」付きのまま残した（テストと運用で ID を指す表記）。全画面の「Issue 番号が画面に出ない」検索テストの正規表現が `#\d+` 型なら、描画結果ではなくテンプレート上のコメントと文言だけを対象にしているか確認してほしい（templ 上は `#{ ... }` なので `#\d` には当たらない）。「#」をやめて「番号 5」等にするなら要判断。
2. 決済理由（ポジション欄の `proposal_close` など）と、イベント表の「主体」「補足」(JSON) はコード/データそのままで残した（理由コード系と判断）。日本語名にするなら要判断。
3. 「あいりの見込み」の「あいり」（MCP クライアントの呼称）はそのまま残した。「AIの見込み」等に変えるか要判断。
