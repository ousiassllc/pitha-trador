# 機能要件: J-Quants の日足・分足の取り込み

`docs/requirements/functional.md` §4 の分割章（行数上限のため別ファイル）。issue #1093（関連: #1074 研究用ラベル）。設計は `docs/architecture/overview/integrations-jquants.md`、表は `docs/architecture/er/tables-jquants.md`、運用は `docs/environment/setup/jquants.md`、MCP は `docs/api/endpoints/paper-results-mcp-jquants.md`（§3.36）。

- FR-JQUANTS-1（読み取りアダプタ）: アプリは J-Quants API V2（`/equities/master`・`/equities/bars/daily`・`/equities/bars/minute`。API キーはヘッダ`x-api-key`、続きは`pagination_key`）の読み取りアダプタを持つ。`*http.Client`とベース URL を差し替えられる。**API キー（秘密`JQUANTS_API_KEY`）が未設定のあいだ、スイッチがオフのあいだ、契約していない側の API（`jquants.plan_daily` / `jquants.plan_minute`が 0）は、HTTP 要求を 1 回も送らない**（数える RoundTripper のテストで固定）。キーはログ・エラー・DB・MCP の応答・通知に出さない。
- FR-JQUANTS-2（既定オフ・Settings だけ）: `jquants.enabled`（既定 0）、`jquants.plan_daily` / `jquants.plan_minute`（既定 0）、`jquants.daily_request_cap`（既定 200、1〜5000）、`jquants.backfill_days`（既定 30、1〜1830）、`jquants.purge_requested`（既定 0）は`runtime_settings`に置き、Settings 画面だけが書く。Paper 実績 MCP の`settings_set`の許可リストに入れない。行が無い・壊れている値は既定（オフ・未契約）として扱う。
- FR-JQUANTS-3（1 日の要求数の上限）: JST の 1 日に送る要求（ページ送りを含む）の数を`research_jquants_fetch_log`で数え、上限に達したら以降の要求を送らない。数えは要求を送る前に 1 文で行う（失敗・中断した要求も数える）。数えは DB にあり、再起動しても戻らず、日が変われば新しく数える。上限に達した実行はエラーにせず終え、残りは翌日に取る。
- FR-JQUANTS-4（研究用の表・取り込みの規則）: 取り込んだ銘柄一覧・日足・分足は、専用の研究用の表（`research_jquants_symbols` / `_daily_bars` / `_minute_bars`。すべて`source='jquants'`）に、自然キーの upsert（冪等）で書く。`market_snapshots`・`daily_bars`・`disclosure_items`・`jev_*`には書かない。埋め戻しは、印（`research_jquants_coverage`）の無い取引日・銘柄だけを、昨日までさかのぼって古い順に取る（今日・休日は取らない。分足は翌日配信のため、直近の空の応答は取り直す。過去 2 年より前は呼ばない）。
- FR-JQUANTS-5（研究用ラベルの付け直し）: 分足を取り終えた日は、その日の研究用ホライズンラベル（`research_horizon_labels`）のうち、`market_snapshots`の足が欠けて付かなかった窓だけを、J-Quants の分足を出口にして付け直す（エントリーは`market_snapshots`の足。記録部品が書いた行は書き換えない）。付け直した行は`exit_source='jquants'`で区別する。ライブのラベル・Calibration・Jev・メタモデルの学習データには触れない。
- FR-JQUANTS-6（解約時の削除）: 運用設定`jquants.purge_requested`（Settings 画面だけ）の依頼を受けて、メンテナンスタスクが J-Quants 由来の行だけを削除する: 研究用の表の全行・取得済みの印・`research_horizon_labels`の`exit_source='jquants'`の行（そのあと日の集計を作り直す）。キーもスイッチも要らず、外部へ要求を送らない。他の出どころの行（`market_snapshots`・`daily_bars`・`disclosure_items`・`jev_*`・記録部品のラベル）は残る（テストで固定）。要求数の記録（件数と固定コードだけ）は残す。
- FR-JQUANTS-7（記録だけ・私的利用）: 取り込んだデータは、ゲート・Policy・Risk・発注・執行・ブローカー・Paper ガード・Live・Jev・RAG の索引・Calibration・メタモデルの学習・自己改善の入力にしない（これらのパッケージが J-Quants の名前を参照しないことをテストで固定）。J-Quants の利用条件（個人の私的利用・外部へ送らない）を守り、取り込んだ値を MCP・ログ・通知に出さない。kabu のアダプタとライブの市場データの経路は変えない。
- FR-JQUANTS-8（状況の読み取り）: 読み取り専用の MCP ツール`jquants_status`が、オン・オフ・契約のフラグ・上限・今日の要求数・表ごとの行数・期間内の日足・分足の日数・直近の失敗数・最後の失敗の固定コード・最後の成功の時刻を返す。API キー・URL・価格・銘柄は返さず、書き込みの手段（スイッチ・削除の依頼）は無い。
