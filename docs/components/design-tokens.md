# デザイントークン

`overview.md` §1 のスタイリング方針。色は Ousiass 共通デザインガイド（brand-guide）のトークンだけを使う（issue #940）。`static/src/css/app.css` が `:root`（Light）と `@media screen and (prefers-color-scheme: dark)` 内の `dark.css`（`app.css` が import）の `:root:not([data-theme="light"])` と `:root[data-theme="dark"]`（Dark。`<html data-theme>` が無ければ OS 設定に追従し（issue #957）、ヘッダーの切替 `molecules.ThemeToggle` が `data-theme="light|dark"` で強制する。選択は localStorage の `pitha-theme` に保存し、`vendor/theme-init.js` が初回描画前に反映する。issue #978。2 つの Dark ブロックは同じ値で、`lib/theme.test.ts` が一致を確かめる。`:root[data-theme="dark"]` も `@media screen` の中に置き、印刷（`@media print`）では OS 設定・保存済みの選択に関わらず `:root` の Light 値のまま = 常に ink on bone（brand-guide §8、issue #1002）。ヘッダー・ナビ・Kill Switch パネル・`#toast-region` は `print:hidden` で印刷から外す）にコアトークン（`--ink` `--bone` `--mute` `--surface` `--border` `--accent` `--accent-soft` `--focus`）と状態色（`--success` `--warning` `--danger` `--info`）を定義し、`@theme inline` で Tailwind のクラス（`text-ink` `bg-bone` `bg-surface` `border-border` `bg-accent` `text-mute` `outline-focus` `text-success` 等）にする。Tailwind 既定のパレット（`slate-*` `blue-*` など）は `--color-*: initial` で無効にしてあり、使うとクラスが生成されず `internal/web/style_test.go` が失敗する。

- ステータスのピル（チップ・バッジ）は `rounded-pill tone-success|warning|danger|info|mute px-3 py-1 text-note`（文字＝状態色、地＝10%。枠は付けない。`app.css` の `@utility tone-*`）。状態は文言でも伝える。中立の `tone-mute` は `--surface-sel` 地に `--mute-on-soft` 文字（`--mute` 文字は `--surface-sel` 上で Light 4.45:1 と AA 4.5:1 未満のため。旧 issue #1022 の `--ink` 文字・10% 地を置き換えた）なので、ピルに `text-mute` を足さない。インラインアラート・通知枠は `banner-*`（下の「アプリ UI のトーン」）。行ホバー（`hover:bg-surface-sel`）の行内のゼロ・欠損表示（騰落率の 0.00・「—」）も、`--mute` が `--surface-sel` 上で AA 未満になる同じ理由で `text-mute` でなく `text-ink`
- Lit のShadow DOMはCSSカスタムプロパティが継承されるため、`static styles` は hex を書かず `var(--ink)` `var(--border)` 等を使う
- フォーカスリングは 2px・offset 2 の `--focus`。`app.css` の `@layer base` が `a` `summary` `button` `select` の `:focus-visible` に当て、Lit の Shadow DOM 内は届かないので `buttonStyles`（`lib/styles.ts`）と `help-mark.ts` が `outline: 2px solid var(--focus)` を持つ。`atoms.Input` / `atoms.Select` / `atoms.Textarea` は `focus-visible:outline focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-focus`（枠線＋40%のにじみ `--ring` ではなく、ボタンと同じ 2px のはっきりした outline。issue #1139）。素の `<select>` を light DOM に描く Lit（`pitha-activity-feed` の絞り込み）は同じクラスの `lightDomFieldClass`（`lib/styles.ts`）を付ける。SSR のフォームは素の `<textarea>` / `<select>` を書かず atoms を通す
- パネル（`<section>` のカード）の本文は `text-ink`。見出し（h2〜h4、ホームのカード見出し `cardTitleClass` も含む）は `text-ink`。`text-mute` は日付・既定値・件数などの補助の `<span>` / キャプションだけ（issue #994）

## アプリ UI のトーン（brand-guide c9956c0a。issue #984 / #1141 / #1139）

- 操作が中心の画面（管理・ダッシュボード）は、ブランドガイドの「アプリ UI」に従い、線ではなく面の濃さで区切り、文字は 3 段だけにする。以降の節の寸法・クラスはこの節と合わせて読む
- 文字は 3 段（`app.css` の `@theme` が持つ Tailwind ユーティリティ `text-title` / `text-item` / `text-note`）。ページタイトル（h1）は `text-title`（28px・700・行間 1.4。`font-bold text-ink`）。節・カード・パネル・モーダルの見出し（h2〜h4）・項目名・フォームのラベル・ボタン・ナビ・タブは `text-item`（15px・600・行間 1.6。`font-semibold`、見出しは `text-ink`）。本文・リスト項目・表本文・値・KPI・チェックボックス/スイッチのラベルは `text-item` の Regular（親が SemiBold のときだけ `font-normal` を足す）。説明・キャプション・チップ・表見出し・ヒント・時刻は `text-note`（13px・400・行間 1.6・`text-mute`。`--surface-sel` の上では `text-mute-on-soft`）。アプリ画面のテンプレートに `text-xs|sm|base|lg|xl|2xl|3xl` や 12 / 14px の中間サイズを使わない。ガイドのスケール `xs 12 / sm 14 / base 16 / lg 18 / xl 24 / 2xl 32 / 3xl 40px` は長文（ダイアログ・ドキュメント）向けに `@theme` へ残し、`internal/web/style_test.go` の `TestCompiledTextScaleMatchesTheGuide` が値を確かめる
- 面と形のトークン（`app.css` の `:root`。Dark の `--surface-sel` だけ `dark.css`）: `--surface-sel`（選択・ホバー・入れ子の地。Light #ebebea / Dark #1e1e21）、`--line-soft`（`--accent` の 6%。Light は ink・Dark は bone の薄い線で、表の行区切りとモーダルの枠にだけ使う。トークンから導くので Dark の複製は無い）、`--mute-on-soft`（`--mute` 85% + `--ink` 15%。`--surface-sel` の上の 13px の `--mute` 文字用）、`--surface-sel-hover`（`--surface-sel` に `--ink` 8%。静かなボタンのホバー）、`--r-card` 16px・`--r-pill` 999px（`rounded-card` / `rounded-pill`）、カードの内側余白 22px（`p-card`）。Tailwind では `bg-surface-sel` `hover:bg-surface-sel-hover` `border-line-soft` `text-mute-on-soft`
- カードは枠も影も付けない `rounded-card bg-surface p-card`（項目どうし 16px = `gap-4`、まとまりどうし 24px = `gap-6`）。カード・モーダルの中の入れ子パネルは `rounded-card bg-surface-sel p-4`、ページの地に直接置く面は `bg-surface`。空状態は `rounded-card bg-surface-sel px-6 py-12 text-center text-mute-on-soft`
- バナー・通知枠は `banner-success|warning|info`（`--surface-sel` の地・16px の角・`text-ink`・先頭に状態色の丸。padding 12 / 16 / 12 / 36px は `banner-*` が持つので、呼び出し側は `text-item` と配置だけ足す）。danger だけは 40% の枠を残す `border banner-danger`。アイコンを自前で持つ `atoms.InlineAlert`（`rounded-card border border-danger/40 bg-surface-sel`）と `atoms.ReloadNotice`（`rounded-card bg-surface-sel`）は、アイコンだけに状態色を使う
- チップ（ステータスのピル・バッジ）は枠なしの `rounded-pill tone-* px-3 py-1 text-note`。ボタンはピル（`rounded-pill`・`text-item font-semibold`）で、主は `bg-accent` 塗り、サブは枠なしの静かな `bg-surface-sel` ピル（ホバー `bg-surface-sel-hover`）、ゴーストは透明（ホバー `bg-surface-sel`）。ナビ・タブは `text-item font-semibold text-ink`・`min-h-10 px-4` で、選択中は `rounded-pill bg-surface-sel` のピル、ほかは透明（ホバー `bg-surface-sel`）。下線（`border-b-2`）もタブ行の `border-b` も無い
- 表は見出し行に下線を引かず（`text-note font-normal text-mute`）、本文の行を `border-b border-line-soft` で区切る（最終行は線なし。`last:border-b-0`）。行ホバーは `hover:bg-surface-sel`、表を囲む面は `rounded-card bg-surface`（カードの中なら囲まない）
- 枠を残す例外: 入力・セレクト・テキストエリア・チェックボックス・スイッチのトラック（`border-border`）、`:focus-visible` の輪、danger のバナー（40%）、浮かぶ面（モーダルは `border border-line-soft` で、見出し行・フッターの区切りも `border-line-soft`。ツールチップも 1px の枠）。カード・表・サブナビ・バナーに 1px の枠を足さない
- 入力欄（input・select・textarea）の角は 8px（`rounded-md`）。ピルにしない（チェックボックスだけ 18px の箱なので `rounded-sm`）
- Kill ボタンは `--danger` の塗りのピル。Jev の「この版をライブに昇格」など、ほかの主操作は `--accent` の主ボタン（`bg-accent text-bone`）
- 浮いている面の枠は今のまま。モーダル・確認ダイアログは `border-line-soft` の 1px（SSR のツールチップは `border-border`、Lit のツールチップは `--line-soft`、ink 塗りのトースト `bg-ink` は枠なし）
- この節の範囲外: #1039 / #1042 / #1043 は、ブランドガイドの追補待ちのため含めない

## フォントとタイポグラフィ（issue #941）

- 本文は `Sora, "Noto Sans JP", sans-serif`（`font-sans`）、コードと桁を揃える数値は `"JetBrains Mono", ui-monospace, monospace`（`font-mono`）。`font-mono` は数値・日時・金額・コードだけに付け、日本語の文言（「買い / 指値」「通過」「決済理由」など）には付けない（Mono の日本語は代替フォントで描かれる）。注文提案の詳細は `ProposalField.Text` で文言の値を分け、Lit の `<dl>` は文言の `dd` に `class="text"` を付けて Sora + Noto Sans JP に戻す。確信度は `font-mono tabular-nums`（issue #1139）。いずれも SIL OFL
- フォントは `@fontsource-variable/{sora,noto-sans-jp,jetbrains-mono}`（`static/package.json` の devDependencies、版は `bun.lock`）から `static/esbuild.config.mjs` が `static/src/dist/fonts/` へ複製し、`fonts.css`（`@font-face`）を `layout` の `<head>` で読む。同一オリジンなので CSP は `font-src 'self'` のまま。canvas（`pitha-price-chart`）は CSS を継承しないため `createChart` の `layout.fontFamily` に明示する
- 太さは Regular(400)・SemiBold(600)・Bold(700) の 3 つ。Bold はページの h1（`text-title font-bold`）だけ。SemiBold は見出し・項目名・フォームのラベル・ボタン・ナビ・タブ（`text-item font-semibold`）に限る。本文・値・表（見出し行も）・チップ・説明は Regular（`css/table.css` が `<th>` の UA 既定の bold を 400 に戻す）。`font-medium` / 本文中の `font-semibold` は使わない（現在のナビ項目は `bg-surface-sel` のピルで示す）
- 表本文は `text-item`、見出し行は `text-note font-normal text-mute`（下線なし）。数値列は `text-right font-mono tabular-nums`（th も右寄せ）。Lit の表は `lib/styles.ts` の `tableStyles`（th = Regular 13px `--mute`・下線なし、td = 15px・上下 10 / 左右 12・下に 1px `--line-soft`（最終行は線なし）、行ホバー `--surface-sel`、数値列は `class="num"`）を `static styles` に足す。銘柄コードの列（スキャナー・スキャン結果・保有ポジション・ホームのポジションの表。ウォッチリスト・注文提案一覧と同じ）も「コード」なので `font-mono`（`td` に付け、SSR と Lit で同じ。issue #1023）。表以外の銘柄コード（ホームの「AIの注文提案」「最近の取引」のリスト項目、銘柄詳細の `h1`）も同じく `font-mono`（リンクなら `<a>`、見出しなら `h1` に付ける。issue #1040）
- ステータスのピル・バッジは Regular（`font-semibold` なし）・`rounded-pill`・`px-3 py-1 text-note`・枠なし。文中の強調は太さでなく `text-ink` 色と `font-mono tabular-nums`（`<strong>` は使わない）
- 通知・アラートの本文は `text-item`（`text-note` は注記・キャプション・チップだけ）。一覧の中身（最近の取引・Kill Switch・交絡要因の `<ul>`）も本文なので `text-item`、時刻など補助だけ `text-note text-mute`。値を伝える行（件数・「N/M 項目」・資金・損失上限までの残り・最終サイクルや学習日時などの行）も `text-note text-mute`（issue #1005 / #1006 / #1019 / #1031 で 12px から 14px に上げた行は、アプリ UI の 13px のノートに揃えた）。計算結果パネルの題名は h3（`text-item font-semibold`）、リスト項目のラベルは Regular の `text-item text-ink`。「注意:」「状態:」のような行頭ラベルは Regular で、色（`text-warning` / `text-ink`）で区別する。KPI の値（勝率・EV・許容ポジションの％など）は `font-mono tabular-nums`。ラベルと値の `<dl>` は、ラベル `text-note text-mute`＜値 `text-item text-ink font-mono tabular-nums`（Regular。サイズと色で主従を付け、太さは使わない。issue #984。スキャンのファネルの項目ラベルも同じ `text-note text-mute`。注意枠の説明文は Regular で、太さを付けない。issue #1031）
- 行間は `@theme` の `--text-*--line-height`（アプリ画面の 3 段: title 1.4 / item 1.6 / note 1.6。長文向けのスケール: xs 1.6 / sm 1.7 / base 1.8 / lg 1.7 / xl 1.5 / 2xl 1.4 / 3xl 1.3）と `body { line-height: 1.8 }`。`leading-relaxed`（1.625）や `line-height: 1.625` は使わず、サイズのクラスが持つ行間に任せる（Lit のツールチップは note の 1.6）。`@theme` は `--text-xl: 1.5rem` / `--text-2xl: 2rem` / `--text-3xl: 2.5rem` で Tailwind 既定（20 / 24 / 30px）を上書きして、長文向けのスケール（xs 12 / sm 14 / base 16 / lg 18 / xl 24 / 2xl 32 / 3xl 40px）をガイドに合わせて保つ。ビルド済み CSS の値は `internal/web/style_test.go` の `TestCompiledTextScaleMatchesTheGuide` が確かめる。見出しの大きさはタグの階層で決め、箇所ごとに選ばない（issue #993 / #1141）: h1 は `text-title`（28・Bold）、h2〜h4 は `text-item`（15・SemiBold）。いずれも `text-ink`。節の h2 の下にあるカード・パネルの見出しは h3（その下の小見出しは h4）にし、見出しのタグと大きさがずれたら大きさでなくタグ（アウトライン）を直す。`sr-only` の見出しは大きさを持たない。旧い管理画面向けの見出しスケール（h1=24 / h2=18 / h3=14。#981）は、この 3 段に置き換わったので導入しない。`internal/web/style_test.go` の `TestTemplHeadingsFollowTheGuideScale` がタグごとの大きさを確かめる。`text-[10px]` は使わない

## 形・余白・線（issue #942）

- 角丸は `app.css` の `:root` に `--r-sm|md|lg|xl|full`（4 / 8 / 12 / 16px / 9999px）と、アプリ UI の `--r-card`（16px）・`--r-pill`（999px）を定義し、`@theme` の `--radius-sm|md|lg|xl|card|pill` がそれを読む。`rounded-sm`（ツールチップ・タグ）・`rounded-md`（入力・セレクト・テキストエリア）・`rounded-card`（カード・パネル・入れ子パネル・表の面・空状態・バナー）・`rounded-pill`（ボタン・チップ・選択中のナビとタブ・セグメント）・`rounded-xl`（モーダル）をそのまま使う。`rounded-full` は点・円・スイッチのトラックだけ。Lit の `static styles` は `var(--r-md)` `var(--r-card)` `var(--r-pill)` 等を使う
- ツールチップは `rounded-sm`・13px（`text-note`）・padding 6×10（`px-[10px] py-1.5`、Lit は `0.375rem 0.625rem`）。本文は非対話で、リンク・ボタンを入れない（リンクは `HelpMark` の外に置く）
- 入力・セレクトは高さ 40px・左右 12px（`h-10 px-3`、`atoms/input.templ` の `fieldBox` と Lit の `lightDomFieldClass`）。呼び出し側は `py-*` で上書きしない。`<textarea>` は高さ固定でないので全周 12px（`p-3`、`atoms/input.templ` の `textareaBox`。1 行目を 40px の入力に揃えるために縦を削らない。issue #1027 / #1029）。入れ子パネル（カード・モーダルの中の `bg-surface-sel`）は `rounded-card`。テーマ切替は `p-1 gap-1`
- 影はモーダルだけ（`shadow-modal` = `--shadow-modal` 0 1px 2px rgba(0,0,0,.06)）。カードは枠も影も付けない。ツールチップは 1px の枠（SSR は `border-border`、Lit の `help-mark.ts` は `--line-soft`）、トーストは `bg-ink` の面で、いずれも `shadow*` を付けない
- 表のセルは上下 10px / 左右 12px（`px-3 py-2.5`）、compact は上下 6px / 左右 8px（`px-2 py-1.5`）の 2 種類。SSR と Lit で同じ値にし、`pr-N` だけの指定はしない。余白は 4px 基準（20px・2px・6px の `px-5` `py-0.5` `mt-1.5` は使わない。表の compact とツールチップの 6px だけ例外）
- ガターは `px-4 lg:px-6`（モバイル 16px / デスクトップ 24px）。セクション間は 48px（`mt-12` / `mb-12`、設定画面の節どうしは `gap-12`）。ページの h1 の下は 24px（`mt-6`）、h2 の下は節でもカード・パネルでも 16px（`mb-4`）、h3 の下は 12px（`mb-3`）。カード・パネルの見出しの下に `mt-*` を重ねない（見出しの `mb-*` が間隔を持つ）
- フォームはラベル→入力が 8px（`flex flex-col gap-2` / `mt-2`）、入力→補足が 4px（`gap-1` / `mt-1`）。メニュー・ナビ項目は項目間 8px（`gap-x-2`）・高さ 40px（`min-h-10`）・左右 16px（`px-4`）・`rounded-pill` `text-item font-semibold text-ink` で、選択中は `bg-surface-sel`、ほかはホバーで `bg-surface-sel`（下線や色だけの強調にしない。issue #984 / #1139）。メインナビ（`organisms/header_nav.templ`）とタブ（`molecules/tab_nav.templ`）が同じレシピ
- 空状態は `rounded-card bg-surface-sel`・`px-6 py-12`（上下 48 / 左右 24）・`text-center text-mute-on-soft`（枠・破線は付けない）。ハッシュ到達時の強調は `target:ring-1 target:ring-mute`

## アイコン（issue #943）

UI アイコンは [Iconoir](https://iconoir.com)（MIT、iconoir 7.12.2 の regular）の SVG を使う。文字記号（×・▲▼）で代用しない。24×24 の viewBox・`stroke-width="1.5"`・`stroke="currentColor"`・装飾なので `aria-hidden`（名前はボタンの `aria-label`）。サイズは `app.css` の `--icon-sm|md|lg`（16 / 20 / 24px）を `icon-sm` / `icon-md` / `icon-lg` のユーティリティで当てる。リンクの矢印も Iconoir（`IconArrowRight` / `IconNavArrowLeft`）で、文字の →・← は使わない。templ は `internal/web/atoms/icon.templ`（`IconXmark` ほか）、Lit は `static/src/components/lib/icons.ts`（`navArrowUp` / `navArrowDown`）に同じパスを置く。足すときは両方に同じパスを足す。

状態ピルは色と文言だけで伝えず、先頭に 16px（`icon-sm`・`currentColor`）の状態アイコンを付ける（C4。issue #1034）。`StatusDot` は Running=`IconCheckCircle` / Paused=`IconWarningTriangle` / Killed=`IconXmarkCircle`、`Badge` は LONG=`IconNavArrowUp` / SHORT=`IconNavArrowDown`（方向は成否ではないので矢印）。`InlineAlert` は従来どおり `IconWarningCircle`。Lit にも `scanner-table/scanner-view.ts` の `directionBadge`（LONG / SHORT）があり、同じ矢印（`lib/icons.ts` の `navArrowUp` / `navArrowDown`。templ の `NavArrowUp/Down` と同じパス）を先頭に付ける。`StatusDot`・`InlineAlert` に当たる Lit のピルは無く、状態アイコンのパスは templ 側だけにある。ほかのピル（`EntryQualityBadge`・設定済み／必須ピル・`tone-*` ブロックなど）は別途。

## モーション（issue #944）

トークンは `app.css` の `:root`（`--motion-fast` 120 / `--motion-base` 180 / `--motion-slow` 280 / `--motion-fade-in` 320 / `--motion-fade-out` 240ms）と `@theme static`（`--ease-out` = cubic-bezier(0.2,0.8,0.2,1)、`--ease-in` = cubic-bezier(0.4,0,1,1)、`--ease-in-out`）。Tailwind は `duration-base|fade-in` 等と `ease-out`、Lit は `var(--motion-fade-in) var(--ease-out)` で参照し、時間・曲線を直書きしない。Web Animations API は `var()` を解決できないので `lib/motion.ts` に同じ数値を置き、`motion.test.ts` が `app.css` と一致することを確認する。`prefers-reduced-motion: reduce` では移動・リップルを出さず、必要な opacity のフェードも 100ms 以下にする。色だけのトランジション（ボタン・テーマ切替・チェックボックス・スイッチ）は Tailwind `motion-reduce:transition-none` / Lit `@media (prefers-reduced-motion: reduce)` で無効にする。

- ボタン・閉じるの押下リップル: `data-ripple` を付けた要素に `static/src/components/ripple/pitha-ripple.ts`（`layout` が読む）が、押した点から広がって消える円（280ms ease-out）を描く。`atoms.Button` / `ButtonLink`・トーストの閉じるは templ が付け、Lit のボタンは `data-ripple` を付ける（`lib/styles.ts` の `buttonStyles` が `position: relative; overflow: hidden`）。ドキュメントのリスナーが `composedPath()` で shadow root 内も拾う
- ツールチップ（`atoms.HelpMark`・Lit の `renderHelpMark`・`scanner-view.ts`）: `opacity` のフェードは開く側（`data-open`）が `--motion-fade-in` の ease-out（320ms）、閉じる側（通常状態）が `--motion-fade-out` の ease-in（240ms）。`visibility` は同じ長さで切り替え、閉じるときはフェードが終わってから隠す。Tailwind は通常状態に `duration-fade-out ease-in`、`data-[open]:duration-fade-in data-[open]:ease-out`、reduced-motion は両方に 100ms（`motion-reduce:duration-100 motion-reduce:data-[open]:duration-100`）。Lit の `help-mark.ts` は `.help-mark-text` と `[data-open]` で `transition` を分ける
- トースト（`htmx-errors/toast-lifecycle.ts`）: 出現は opacity と 8px の `translateY` を 320ms ease-out、退出は opacity を 240ms ease-in で待ってから `remove()`。Web Animations API が無ければ即時
- インラインアラート（`atoms.InlineAlert`）: 出現は `alert-in`（320ms ease-out）。消去は、枠に残っているアラートを新しい応答が置き換えるとき、`pitha-htmx-errors.ts` の `htmx:beforeSwap` が `HX-Reswap` を `innerHTML swap:240ms`（reduced-motion は 100ms）に上書きして swap を待たせ、htmx が枠に付ける `htmx-swapping` の間 `app.css` の `.htmx-swapping > [data-inline-alert]`（`alert-out`、240ms ease-in）でフェードアウトする。空の枠には待たせず即時に出す

## 部品・オーバーレイ（issue #945）

- ボタンは主（`bg-accent text-bone`）/ サブ（枠なしの静かな `bg-surface-sel text-ink`、ホバー `bg-surface-sel-hover`）/ ゴースト（透明、ホバー `bg-surface-sel`）/ 危険（`bg-danger text-bone`）の 4 種（Lit の Kill ボタンはホバーで面を派生色にせず `--danger` のまま、`--ink` の 1px の内側リング（`box-shadow: inset 0 0 0 1px var(--ink)`）で応える。issue #1030）、`rounded-pill`・`text-item font-semibold`・disabled は opacity .4・標準は高さ 40px（`min-h-10 px-4`）、小は高さ 32px（`min-h-8`）、ページ送りは高さ 36px（`min-h-9`、`ButtonPager`）。Lit の共通ボタン（`lib/styles.ts` の `buttonStyles`）もサブの小（高さ 32px・15px。`box-sizing: border-box`・縦 padding なし・`white-space: nowrap` で、ラベルの長さや折り返しに関わらず `atoms.Button` の小と同じ高さ。issue #984）で、`border: 0`・`border-radius: var(--r-pill)`・`background: var(--surface-sel)`（hover は `--surface-sel-hover`）。テキストリンクは Regular・`underline decoration-mute`

- チャートの色は `lib/chart-theme.ts` がトークンを読んで渡す（陽線 = `--ink` の塗り、陰線 = `--surface` 地に `--ink` 枠の中空、買いマーカー = `--success`、売りマーカー = `--warning`、VWAP = `--info`、出来高 = `--mute` 50%、精度線 = `--ink`、完全較正線 = `--mute`、軸・グリッド = `--border`、クロスヘア線 = `--mute`・軸ラベルの地 = `--ink`）。テーマが切り替わる（OS 設定の変更、またはヘッダーの切替が出す `pitha-theme-change`）たびに `ColorSchemeController` が色を読み直す。印刷（`beforeprint` / `print` メディアの一致から `afterprint` / 不一致まで）の間は、画面が Dark でも Light のトークンで描き直す（ガイド §8 印刷は常に ink on bone）。Chrome は `beforeprint` のあとに描き直した canvas を空白で印刷するため（lightweight-charts の `clearRect` が PDF で全面マスクになる）、印刷中は `lib/chart-theme.ts` の `syncPrintSnapshot` が `takeScreenshot()` の静止画を重ねて表示用チャートを隠し、静止画は `beforeprint` 時点（画面レイアウト）の大きさのビットマップなので、印刷レイアウトでコンテナ幅が変わっても縦横比を保つよう `object-fit: contain`（左上寄せ）で表示する。`afterprint` で外して Dark の色へ戻す。印刷中にホスト要素が DOM から外れた場合は `clearPrintSnapshot` が静止画とコンテナの `position` を外す（再接続時に古い静止画がチャートに被さらないようにする）。`printing` はモジュール全体の状態なので、`ColorSchemeController` は接続時に `matchMedia('print')` から再同期する。系列色は `--success` `--warning` `--info` `--mute` `--ink` だけで、`--danger` は使わない。ヒートマップは `--ink` を `--surface` に混ぜた濃淡（4〜30%）と `--ink` 文字、数値併記。セルは `--r-card` の角で枠なし、サンプルなしは `--surface-sel` 地（枠・破線なし）と `--mute-on-soft` 文字
