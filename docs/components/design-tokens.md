# デザイントークン

`overview.md` §1 のスタイリング方針。色は Ousiass 共通デザインガイド（brand-guide）のトークンだけを使う（issue #940）。`static/src/css/app.css` が `:root`（Light）と `@media screen and (prefers-color-scheme: dark)` 内の `dark.css`（`app.css` が import）の `:root:not([data-theme="light"])` と `:root[data-theme="dark"]`（Dark。`<html data-theme>` が無ければ OS 設定に追従し（issue #957）、ヘッダーの切替 `molecules.ThemeToggle` が `data-theme="light|dark"` で強制する。選択は localStorage の `pitha-theme` に保存し、`vendor/theme-init.js` が初回描画前に反映する。issue #978。2 つの Dark ブロックは同じ値で、`lib/theme.test.ts` が一致を確かめる。`:root[data-theme="dark"]` も `@media screen` の中に置き、印刷（`@media print`）では OS 設定・保存済みの選択に関わらず `:root` の Light 値のまま = 常に ink on bone（brand-guide §8、issue #1002）。ヘッダー・ナビ・Kill Switch パネル・`#toast-region` は `print:hidden` で印刷から外す）にコアトークン（`--ink` `--bone` `--mute` `--surface` `--border` `--accent` `--accent-soft` `--focus`）と状態色（`--success` `--warning` `--danger` `--info`）を定義し、`@theme inline` で Tailwind のクラス（`text-ink` `bg-bone` `bg-surface` `border-border` `bg-accent` `text-mute` `outline-focus` `text-success` 等）にする。Tailwind 既定のパレット（`slate-*` `blue-*` など）は `--color-*: initial` で無効にしてあり、使うとクラスが生成されず `internal/web/style_test.go` が失敗する。

- ステータスのピル・インラインアラートは `border tone-success|warning|danger|info|mute`（文字＝状態色、枠＝40%、地＝10%。`app.css` の `@utility tone-*`）に形（角丸・padding）だけを足す。状態は文言でも伝える
- Lit のShadow DOMはCSSカスタムプロパティが継承されるため、`static styles` は hex を書かず `var(--ink)` `var(--border)` 等を使う
- フォーカスリングは 2px・offset 2 の `--focus`。`app.css` の `@layer base` が `a` `summary` `button` `select` の `:focus-visible` に当て、Lit の Shadow DOM 内は届かないので `buttonStyles`（`lib/styles.ts`）と `help-mark.ts` が `outline: 2px solid var(--focus)` を持つ。`atoms.Input` / `atoms.Select` / `atoms.Textarea` は `focus-visible:border-focus focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-focus/40`（`--ring` = `--focus` 40%。`outline-none` は同じ要素に必ずリングを出すこの場合だけ）。素の `<select>` を light DOM に描く Lit（`pitha-activity-feed` の絞り込み）は同じクラスの `lightDomFieldClass`（`lib/styles.ts`）を付ける。SSR のフォームは素の `<textarea>` / `<select>` を書かず atoms を通す
- パネル（`<section>` のカード）の本文は `text-ink`。見出し（h2〜h4、ホームのカード見出し `cardTitleClass` も含む）は `text-ink`。`text-mute` は日付・既定値・件数などの補助の `<span>` / キャプションだけ（issue #994）

## フォントとタイポグラフィ（issue #941）

- 本文は `Sora, "Noto Sans JP", sans-serif`（`font-sans`）、コードと桁を揃える数値は `"JetBrains Mono", ui-monospace, monospace`（`font-mono`）。いずれも SIL OFL
- フォントは `@fontsource-variable/{sora,noto-sans-jp,jetbrains-mono}`（`static/package.json` の devDependencies、版は `bun.lock`）から `static/esbuild.config.mjs` が `static/src/dist/fonts/` へ複製し、`fonts.css`（`@font-face`）を `layout` の `<head>` で読む。同一オリジンなので CSP は `font-src 'self'` のまま。canvas（`pitha-price-chart`）は CSS を継承しないため `createChart` の `layout.fontFamily` に明示する
- 太さは Regular(400) と SemiBold(600) だけ。SemiBold は見出し・ボタン・表の見出し行に限る。ナビ・リンク・ラベル・値に `font-medium` / `font-bold` / 本文中の `font-semibold` を使わない（現在のナビ項目は `text-ink` の色で示す）
- 表本文は `text-sm`、見出し行は `text-xs font-semibold`。数値列は `text-right font-mono tabular-nums`（th も右寄せ）。Lit の表は `lib/styles.ts` の `tableStyles`（th = SemiBold 12px `--mute` + 下線 1px、td = 上下 10 / 左右 12、数値列は `class="num"`）を `static styles` に足す
- ステータスのピル・バッジは Regular（`font-semibold` なし）・`rounded-full`・`text-xs`。文中の強調は太さでなく `text-ink` 色と `font-mono tabular-nums`（`<strong>` は使わない）
- 通知・アラートの本文は `text-sm`（`text-xs` は注記・キャプション・バッジだけ）。一覧の中身（最近の取引・Kill Switch・交絡要因の `<ul>`）も本文なので `text-sm`、時刻など補助だけ `text-xs text-mute`。値を伝える行（件数・「N/M 項目」・資金・損失上限までの残り・最終サイクルや学習日時などの行）も `text-sm text-mute`（issue #1005 / #1006）。計算結果パネルの題名は h3（`text-xl`）、リスト項目のラベルは Regular の `text-base text-ink`。「注意:」「状態:」のような行頭ラベルは Regular で、色（`text-warning` / `text-ink`）で区別する。KPI の値（勝率・EV・許容ポジションの％など）は `font-mono tabular-nums`。ラベルと値の `<dl>` は、ラベル `text-sm text-mute`＜値 `text-xl text-ink font-mono tabular-nums`（Regular。サイズと色で主従を付け、太さは使わない。issue #984）
- 行間は `@theme` の `--text-*--line-height`（xs 1.6 / sm 1.7 / base 1.8 / lg 1.7 / xl 1.5 / 2xl 1.4 / 3xl 1.3）と `body { line-height: 1.8 }`。`leading-relaxed`（1.625）や `line-height: 1.625` は使わず、サイズのクラスが持つ行間に任せる（Lit のツールチップは xs の 1.6）。サイズは `@theme` の `--text-xl: 1.5rem` / `--text-2xl: 2rem` / `--text-3xl: 2.5rem` で Tailwind 既定（20 / 24 / 30px）を上書きして、ガイドのスケール（xs 12 / sm 14 / base 16 / lg 18 / xl 24 / 2xl 32 / 3xl 40px）に合わせる。ビルド済み CSS の値は `internal/web/style_test.go` の `TestCompiledTextScaleMatchesTheGuide` が確かめる。見出しの大きさはタグの階層で決め、箇所ごとに選ばない（issue #993）: h1 は `text-3xl`（40）、h2 は `text-2xl`（32・行間 1.4）、h3 は `text-xl`（24）、h4 は `text-lg`（18）。いずれも SemiBold・`text-ink`。節の h2 の下にあるカード・パネルの見出しは h3（その下の小見出しは h4）にし、見出しのタグと大きさがずれたら大きさでなくタグ（アウトライン）を直す。`sr-only` の見出しは大きさを持たない。ガイドの管理画面向けの小さい見出しスケール（h1=24 / h2=18 / h3=14）は未決（#981）で、導入しない。`internal/web/style_test.go` の `TestTemplHeadingsFollowTheGuideScale` がタグごとの大きさを確かめる。`text-[10px]` は使わない

## 形・余白・線（issue #942）

- 角丸は `app.css` の `:root` に `--r-sm|md|lg|xl|full`（4 / 8 / 12 / 16px / 9999px）を定義し、`@theme` の `--radius-sm|md|lg|xl` がそれを読む。`rounded-sm`（ツールチップ・タグ）・`rounded-md`（入力・ボタン・入れ子パネル）・`rounded-lg`（カード・パネル・空状態）・`rounded-xl`（モーダル）・`rounded-full`（ピル）をそのまま使う。Lit の `static styles` は `var(--r-md)` 等を使う
- ツールチップは `rounded-sm`・12px・padding 8×12（`px-3 py-2`、Lit は `0.5rem 0.75rem`）
- 入力・セレクトは高さ 40px・左右 12px（`h-10 px-3`、`atoms/input.templ` の `fieldBox` と Lit の `lightDomFieldClass`）。呼び出し側は `py-*` で上書きしない（`<textarea>` だけ `px-3 py-1`）。入れ子パネル（カード・モーダルの中の `bg-bone`）は `rounded-md`。テーマ切替は `p-1 gap-1`
- 影はモーダルだけ（`shadow-modal` = `--shadow-modal` 0 1px 2px rgba(0,0,0,.06)）。カード・ツールチップ・トーストは 1px の `border-border` で区切り、`shadow*` を付けない
- 表のセルは上下 10px / 左右 12px（`px-3 py-2.5`）、compact は上下 6px / 左右 8px（`px-2 py-1.5`）の 2 種類。SSR と Lit で同じ値にし、`pr-N` だけの指定はしない。余白は 4px 基準（20px・2px・6px の `px-5` `py-0.5` `mt-1.5` は使わない。表の compact の 6px だけ例外）
- ガターは `px-4 lg:px-6`（モバイル 16px / デスクトップ 24px）。セクション間は 48px（`mt-12` / `mb-12`、設定画面の節どうしは `gap-12`）。ページの h1 の下は 24px（`mt-6`）、h2 の下は節でもカード・パネルでも 24px（`mb-6`）、h3 の下は 12px（`mb-3`）。カード・パネルの見出しの下に `mt-*` を重ねない（見出しの `mb-*` が間隔を持つ）
- フォームはラベル→入力が 8px（`flex flex-col gap-2` / `mt-2`）、入力→補足が 4px（`gap-1` / `mt-1`）。メニュー・ナビ項目は項目間 8px（`gap-x-2`）・高さ 40px（`min-h-10`）・左右 12px（`px-3`）・`text-base` Regular（SemiBold にしない。issue #984）で、メインナビ（`organisms/header_nav.templ`）とタブ（`molecules/tab_nav.templ`）が同じレシピ
- 空状態は `rounded-lg border border-dashed border-border`・`px-6 py-12`（上下 48 / 左右 24）・`text-center text-mute`。ハッシュ到達時の強調は `target:ring-1 target:ring-mute`

## アイコン（issue #943）

UI アイコンは [Iconoir](https://iconoir.com)（MIT、iconoir 7.12.2 の regular）の SVG を使う。文字記号（×・▲▼）で代用しない。24×24 の viewBox・`stroke-width="1.5"`・`stroke="currentColor"`・装飾なので `aria-hidden`（名前はボタンの `aria-label`）。サイズは `app.css` の `--icon-sm|md|lg`（16 / 20 / 24px）を `icon-sm` / `icon-md` / `icon-lg` のユーティリティで当てる。リンクの矢印も Iconoir（`IconArrowRight` / `IconNavArrowLeft`）で、文字の →・← は使わない。templ は `internal/web/atoms/icon.templ`（`IconXmark` ほか）、Lit は `static/src/components/lib/icons.ts`（`navArrowUp` / `navArrowDown`）に同じパスを置く。足すときは両方に同じパスを足す。

## モーション（issue #944）

トークンは `app.css` の `:root`（`--motion-fast` 120 / `--motion-base` 180 / `--motion-slow` 280 / `--motion-fade-in` 320 / `--motion-fade-out` 240ms）と `@theme static`（`--ease-out` = cubic-bezier(0.2,0.8,0.2,1)、`--ease-in` = cubic-bezier(0.4,0,1,1)、`--ease-in-out`）。Tailwind は `duration-base|fade-in` 等と `ease-out`、Lit は `var(--motion-fade-in) var(--ease-out)` で参照し、時間・曲線を直書きしない。Web Animations API は `var()` を解決できないので `lib/motion.ts` に同じ数値を置き、`motion.test.ts` が `app.css` と一致することを確認する。`prefers-reduced-motion: reduce` では移動・リップルを出さず、必要な opacity のフェードも 100ms 以下にする。

- ボタン・閉じるの押下リップル: `data-ripple` を付けた要素に `static/src/components/ripple/pitha-ripple.ts`（`layout` が読む）が、押した点から広がって消える円（280ms ease-out）を描く。`atoms.Button` / `ButtonLink`・トーストの閉じるは templ が付け、Lit のボタンは `data-ripple` を付ける（`lib/styles.ts` の `buttonStyles` が `position: relative; overflow: hidden`）。ドキュメントのリスナーが `composedPath()` で shadow root 内も拾う
- ツールチップ（`atoms.HelpMark`・Lit の `renderHelpMark`・`scanner-view.ts`）: `opacity` のフェードは開く側（`data-open`）が `--motion-fade-in` の ease-out（320ms）、閉じる側（通常状態）が `--motion-fade-out` の ease-in（240ms）。`visibility` は同じ長さで切り替え、閉じるときはフェードが終わってから隠す。Tailwind は通常状態に `duration-fade-out ease-in`、`data-[open]:duration-fade-in data-[open]:ease-out`、reduced-motion は両方に 100ms（`motion-reduce:duration-100 motion-reduce:data-[open]:duration-100`）。Lit の `help-mark.ts` は `.help-mark-text` と `[data-open]` で `transition` を分ける
- トースト（`pitha-htmx-errors.ts`）: 出現は opacity と 8px の `translateY` を 320ms ease-out、退出は opacity を 240ms ease-in で待ってから `remove()`。Web Animations API が無ければ即時
- インラインアラート（`atoms.InlineAlert`）: 出現は `alert-in`（320ms ease-out）。消去は、枠に残っているアラートを新しい応答が置き換えるとき、`pitha-htmx-errors.ts` の `htmx:beforeSwap` が `HX-Reswap` を `innerHTML swap:240ms`（reduced-motion は 100ms）に上書きして swap を待たせ、htmx が枠に付ける `htmx-swapping` の間 `app.css` の `.htmx-swapping > [data-inline-alert]`（`alert-out`、240ms ease-in）でフェードアウトする。空の枠には待たせず即時に出す

## 部品・オーバーレイ（issue #945）

- ボタンは主（`bg-accent text-bone`）/ サブ（透明＋1px `border-border`）/ ゴースト / 危険（`bg-danger text-bone`）の 4 種、SemiBold・`rounded-md`・disabled は opacity .4・小は高さ 32px（`min-h-8`・`text-sm`）、ページ送りは高さ 36px（`min-h-9`、`ButtonPager`）。Lit の共通ボタン（`lib/styles.ts` の `buttonStyles`）もサブの小（高さ 32px・14px。`box-sizing: border-box`・縦 padding なし・`white-space: nowrap` で、ラベルの長さや折り返しに関わらず `atoms.Button` の小と同じ高さ。issue #984）で、`background: transparent` + 1px `--border`（hover だけ `--accent-soft`）。テキストリンクは Regular・`underline decoration-mute`
- セグメント（Lit の `pitha-calibration-heatmap` のホライズン切替）は `--accent-soft` 地の角丸トラック（padding 4px・`--r-md`）に、選択中の項目だけ `--surface` の面。`--accent` 塗りは主ボタン（主要アクション）だけで、切替には使わない。a11y は `role="group"` + `aria-pressed`
- 設定の on/off（有効・無効、許可・不許可）は `atoms.Switch`（OS の checkbox 見た目を出さない）。実装の Switch は MCP・Jev プロンプトのパネルで、いずれも「保存」ボタン付きの `hx-post` フォーム内にあり、押すだけでは保存されない。複数の項目から選ぶ選択肢（`DataExportPanel` の対象 `kinds` など）は checkbox のまま
- モーダルは `rounded-xl`・`shadow-modal`・スクラム（`--scrim`）と本体が一緒にフェード（`app.css` の `dialog[data-modal]`、開 320ms ease-out・閉 240ms ease-in、`prefers-reduced-motion` では 100ms）。確認・破壊的操作（`hx-confirm`、Kill）は `molecules.ConfirmDialog`
- トーストは画面下中央・端から 24px・高さ 40px のピル（`bg-ink text-bone`）・同時 1 つ（新しいものが置き換える）・3 秒。文言は 1 文の短文（`whitespace-nowrap` で収まる長さ）にし、補足は画面上の文言か `atoms.HelpMark` に移す（例: 立会時間外の決済は「立会時間外のため決済できません。」だけ、「次の立会で再度お試しください。」はポジション表の HelpMark）。長さが定まらない理由（`experiment.IsInvalid` の reason など）はトーストに載せずログに書く。エラー詳細とフォーム検証はトーストにせず `atoms.InlineAlert`（フォーム内のエラー欄）に出す
- z-index は `--z-dropdown` 100（ツールチップ）/ `--z-toast` 500（`z-[var(--z-dropdown)]` のように使う）
- 確認モーダル（`#confirm-dialog`）の外側クリックでの閉じは、`layout.document` が全ページで読む `modal/pitha-modal.js` が担う（確認ダイアログも `dialog[data-modal]`）
- チャートの色は `lib/chart-theme.ts` がトークンを読んで渡す（陽線 = `--ink` の塗り、陰線 = `--surface` 地に `--ink` 枠の中空、買いマーカー = `--success`、売りマーカー = `--warning`、VWAP = `--info`、出来高 = `--mute` 50%、精度線 = `--ink`、完全較正線 = `--mute`、軸・グリッド = `--border`、クロスヘア線 = `--mute`・軸ラベルの地 = `--ink`）。テーマが切り替わる（OS 設定の変更、またはヘッダーの切替が出す `pitha-theme-change`）たびに `ColorSchemeController` が色を読み直す。印刷（`beforeprint` / `print` メディアの一致から `afterprint` / 不一致まで）の間は、画面が Dark でも Light のトークンで描き直す（ガイド §8 印刷は常に ink on bone）。Chrome は `beforeprint` のあとに描き直した canvas を空白で印刷するため（lightweight-charts の `clearRect` が PDF で全面マスクになる）、印刷中は `lib/chart-theme.ts` の `syncPrintSnapshot` が `takeScreenshot()` の静止画を重ねて表示用チャートを隠し、静止画は `beforeprint` 時点（画面レイアウト）の大きさのビットマップなので、印刷レイアウトでコンテナ幅が変わっても縦横比を保つよう `object-fit: contain`（左上寄せ）で表示する。`afterprint` で外して Dark の色へ戻す。印刷中にホスト要素が DOM から外れた場合は `clearPrintSnapshot` が静止画とコンテナの `position` を外す（再接続時に古い静止画がチャートに被さらないようにする）。`printing` はモジュール全体の状態なので、`ColorSchemeController` は接続時に `matchMedia('print')` から再同期する。系列色は `--success` `--warning` `--info` `--mute` `--ink` だけで、`--danger` は使わない。ヒートマップは `--ink` を `--surface` に混ぜた濃淡（4〜30%）と `--ink` 文字、数値併記。サンプルなしは `--bone` と破線枠
